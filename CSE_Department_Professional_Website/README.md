# Professional CSE Department Website — React

A responsive, multi-page Computer Science & Engineering department website inspired by the information architecture of leading university CSE department websites.

## Included pages

- Home
- About
- Academics
- Faculty
- Research
- Students
- Facilities
- Placements
- News & Events
- Contact

## Run

```bash
npm install
npm start
```

Open http://localhost:3000

## Customize

Edit `src/data.js` to replace:
- University name
- Department email and phone
- Address
- Faculty
- Programmes
- Research areas
- News/events
- Facilities
- Recruiters

Replace the sample placement figures with official data before publishing.

## Notes

The website intentionally uses CSS-generated visual placeholders so it runs without downloading image assets. Replace the hero/campus/facility placeholders with your college photographs and logo for the final deployment.
